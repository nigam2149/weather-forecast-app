# ☁️ Weather Forecast App

A modern, responsive weather forecast application built with React that provides real-time weather data for cities worldwide.

![Weather App](https://img.shields.io/badge/React-18.0+-blue.svg)
![License](https://img.shields.io/badge/license-MIT-green.svg)

## ✨ Features

- 🌍 **Real-time Weather Data** - Fetches live weather information using OpenWeather API
- 🎨 **Glassmorphism UI** - Beautiful modern design with glass effects and gradients
- 📱 **Fully Responsive** - Works seamlessly on desktop, tablet, and mobile devices
- 🌈 **Dynamic Themes** - Weather-based gradient colors that change with conditions
- ⏰ **Live Clock** - Real-time clock and date display
- 💨 **Detailed Info** - Temperature, humidity, wind speed, pressure, and more
- 🔍 **Smart Search** - Search any city worldwide instantly
- ⚡ **Smooth Animations** - CSS animations with floating effects and transitions
- ⚠️ **Error Handling** - User-friendly error messages and loading states
- 🎭 **Weather Emojis** - Dynamic weather icons based on conditions

## 🛠️ Technologies Used

- **React.js** - Frontend framework
- **JavaScript (ES6+)** - Programming language
- **CSS3** - Styling with animations, gradients, and glassmorphism
- **OpenWeather API** - Real-time weather data
- **Vite** - Build tool and development server
- **React Hooks** - useState, useEffect for state management

## 🚀 Getting Started

### Prerequisites

Make sure you have installed:
- [Node.js](https://nodejs.org/) (v14 or higher)
- npm or yarn package manager

### Installation

1. **Clone the repository**
```bash
git clone https://github.com/nigam2149/weather-forecast-app.git
```

2. **Navigate to project directory**
```bash
cd weather-forecast-app
cd weather
```

3. **Install dependencies**
```bash
npm install
```

4. **Start the development server**
```bash
npm run dev
```

5. **Open your browser**
```
Visit: http://localhost:5173
```

## 🔑 API Configuration

This project uses the OpenWeather API. The API key is included for demonstration purposes.

To use your own API key:
1. Get a free API key from [OpenWeatherMap](https://openweathermap.org/api)
2. Replace the API key in `App.jsx`
